# Estudos em Java ☕🚀

Este repositório contém os exercícios e projetos desenvolvidos durante o bootcamp de Java com foco em AWS.  
O objetivo é registrar minha evolução na linguagem Java, praticar lógica de programação e aplicar os conceitos aprendidos no desenvolvimento de aplicações.

📌 Conteúdos abordados:
- Fundamentos de Java  
- Estruturas de controle (if/else, laços, etc.)  
- Lógica de programação  
- Boas práticas iniciais  
- Integração com conceitos de Cloud (AWS)  

📈 Este repositório será atualizado conforme avanço nos estudos.
